# Causal Resolution Limit Under Vanishing Overlap

**Status:** exact information-theoretic calculation + simulation plan. Not part of submission.

## Question

Suppose a latent microstate is perfectly observed, but residual treatment variation within that state shrinks with sample size. Can we even determine whether that microstate has its own causal effect?

## Gaussian local experiment

In a microstate with n_N = pi N observations,

    T_tilde_i ~ N(0, sigma_N^2),
    Y_tilde_i = theta T_tilde_i + U_i,
    U_i ~ N(0, sigma_U^2),

with sigma_N=N^{-alpha}.

Compare two causal models:
    H0: theta = theta_0
    H1: theta = theta_0 + delta_N.

Conditional on T_tilde, the KL divergence is

    KL(P_1 || P_0 | T)
      = delta_N^2 / (2 sigma_U^2) * sum_i T_tilde_i^2.

Taking expectation,

    E KL
      = pi N delta_N^2 sigma_N^2 / (2 sigma_U^2)
      = C * delta_N^2 * N^(1-2 alpha).

If delta_N=N^{-beta},

    E KL = C * N^(1 - 2 alpha - 2 beta).

Therefore the detection boundary is

    alpha + beta = 1/2.

### Regimes

- alpha + beta < 1/2: KL -> infinity; heterogeneity is asymptotically detectable.
- alpha + beta = 1/2: KL -> constant; nontrivial local asymptotic testing problem.
- alpha + beta > 1/2: KL -> 0; total variation -> 0 by Pinsker, so no test can reliably distinguish the two causal-effect models.

Most strikingly, if alpha>1/2, even **constant nonzero heterogeneity** (beta=0) becomes asymptotically undetectable as N grows because the treatment loses variation faster than sample size accumulates information.

This is true with:
- perfectly observed state labels;
- correctly specified nuisance functions;
- Gaussian outcomes;
- no representation uncertainty.

Thus there is a genuine **causal resolution limit**: observational/generative state distinctions can remain perfectly visible while causal effect distinctions become information-theoretically invisible.

## Relation to the refinement paradox

The earlier O_p(N^(alpha-1/2)) slope error is the estimation manifestation of the same information boundary. The KL calculation strengthens it from "this estimator performs badly" to "no procedure can uniformly recover/test the fine-state effect distinction" when alpha+beta>1/2.

This also explains why target coarsening/partial pooling is not merely regularization convenience. Beyond the resolution boundary, insisting on a separate fine-state causal parameter asks the data to identify a distinction carrying asymptotically zero causal information.

## Important qualification

The parameter itself is still mathematically defined. "Undetectable" here refers to the specified local sequence of observational experiments: the distributions generated by theta_0 and theta_0+delta_N become mutually indistinguishable in total variation. Interventions or external information could restore identification/information.

## Next empirical test

Simulate likelihood-ratio/Wald tests over alpha and beta. Power should:
- approach 1 below the boundary;
- remain nontrivial near the boundary;
- collapse toward test size above it.

Also compare generative state-classification accuracy, which can remain near 1 throughout because the state emissions need not weaken with treatment overlap.
