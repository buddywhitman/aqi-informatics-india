The question

Does cutting NO₂ cut PM₂.₅?

A forecast cannot answer this. The atmosphere has a hidden state, such as stagnation or ventilation, that raises both pollutants together.

We never observe that state. We only see weather proxies.

Approach

Infer the state, then estimate carefully.

Hidden Markov model gives a probability of each regime at each hour.

Cross-fitting skips neighbouring hours so time dependence cannot leak.

A regularized coupled score gives one effect per regime.

Key discovery

A worse state estimate can look better.

We call it phantom causal resolution: error rises while the usual conditioning check improves, up to 70×.

The rules: what we build from them

Three rules shape the estimator.

Orthogonality

∂(m,μ) E ψk=0\partial_{(m,\mu)}\,\mathbb E\,\psi_k=0∂(m,μ)​Eψk​=0

Condition nuisances on the posterior: first-order errors drop out for every posterior.

Error bound

∥θ^−θ∗∥≲εγλmin⁡(J)\|\hat\theta-\theta^*\|\lesssim\frac{\varepsilon_\gamma}{\lambda_{\min}(J)}∥θ^−θ∗∥≲λmin​(J)εγ​​

State error and nuisance error add; neither hides the other.

Residual-state bias

B=a b va2v+σ2B=\frac{a\,b\,v}{a^{2}v+\sigma^{2}}B=a2v+σ2abv​

State error × treatment shift × outcome shift, over a variance the shift inflates.

Conclusions

Two rules survive.

Design

Use the posterior as an adjustment feature. Use it as a weight only on the target.

Reporting

State the leftover state variance, the regime shifts, a robustness value, simple baselines, and aligned placebos.
