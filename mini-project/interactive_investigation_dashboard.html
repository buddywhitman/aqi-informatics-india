Diagnostic Proof: Scale Distortion Under Affine Transformations

A central analytical finding of this project centers on why zero observations crossed the Suspicious threshold (> 65). On raw PM2.5, concentrations more than doubled (> 100% surge) across 42 separate hours, with surges exceeding 435%.

However, the project rule evaluated relative jump on the rescaled pollution_index:

Index = 100 + 25 × Score
Relative Jump = |Index_t - Median_6h| / (Median_6h + 1)

Let y = ax + b represent an affine transformation with an additive offset b = 100. The relative change of y compared to x is:

Δy / y = a Δx / (ax + b) = Δx / (x + b/a) < Δx / x

Because b = 100, the denominator is anchored around 100 to 140. For a relative jump to exceed 1.0, the index would have had to jump by over +100 points in a single hour. Since the entire monthly range of the index was bounded between 66.4 and 163.8, an instantaneous +100 jump was mathematically impossible. The maximum observed index jump was 0.629. Consequently, the Large Jump flag remained 0 across all 701 hours.

Key Methodological Conclusion: Affine transformations preserve rank order and linear correlation, but fundamentally compress ratio metrics. Scale-dependent heuristic thresholds cannot be blindly transferred across transformed coordinate spaces without re-calibration.
