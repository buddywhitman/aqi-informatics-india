 Delivery and Assessment Plan of LOs# 
Learning Outcome (LO) mapped to the course 
Delivery and assessment Plan 
LO LO statement 
   1 Knowledge and Understanding 
Fundamental knowledge of data science concepts, 
Python programming, data analysis libraries, statistical 
methods, probability, machine learning, and tutorials, 
and laboratory 
Assessment: Assignments, quizzes, laboratory 
exercises, and written examinations. 
2 Engineering Analysis 
Analyze datasets using inferential statistics, 
probability, statistical tools, regression, classification, 
clustering 
Assessment: Assignments, quizzes, programming 
assignments, and written examinations. 
3 Design/Development of Solutions 
Students develop Python -based data analysis and 
machine learning solutions by selecting appropriate 
preprocessing methods, statistical techniques, 
supervised and unsupervised learning algorithms for 
different datasets.  
Assessment: Mini-projects, programming assignments, 
laboratory assessments, and project evaluation. 
4 Investigation 
Investigate real -world datasets by collecting, 
preprocessing, visualizing, analyzing, and interpreting 
data using statistical and machine learning techniques.  
Assessment: Laboratory experiments, case studies, 
project reports. 
L17 Planning Skills 
Students plan and execute data analysis workflows, 
organize datasets, select suitable algorithms, manage 
project timelines, and document the analysis process 
during laboratory exercises and mini-projects.  
Assessment: Project planning, laboratory records, 
assignments, and project evaluation. 
L18 Continuous Professional Development  
Students develop self -learning skills by exploring 
emerging Python libraries, machine learning 
techniques, and recent advancements in data science 
through independent study, online resources, and 
project work.  
Assessment: Self -learning assignments, seminar 
presentations, project work, and continuous internal 
assessment.
